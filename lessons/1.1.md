# Архитектура рабочей книги и средства контроля расчетов

Это занятие загружается непосредственно из GitHub.

## Архитектура модели

Финансовую модель удобно разделять на несколько функциональных слоев:

1. Исходные данные.
2. Предпосылки.
3. Расчеты.
4. Представление результатов.

Такое разделение позволяет отделить вводимые пользователем значения от вычислений и итогового представления результатов.

> [!WARNING]
> Изменяемые предпосылки не следует записывать числовыми константами непосредственно внутри расчетных формул.

### Пример

```excel
Плохо: =C8*0,15
Лучше: =C8*НормативАренды
```

В первом варианте значение `0,15` скрыто внутри формулы. Если норматив изменится, необходимо будет искать все формулы, в которых использована эта константа.

Во втором варианте предпосылка хранится отдельно и используется как единый источник значения.

## Предпосылки

Предпосылки – это параметры модели, которые могут изменяться и влияют на результат расчетов.

Например:

- ставка налога;
- норматив затрат;
- прогнозный курс валюты;
- ставка дисконтирования;
- темп роста;
- стоимость ресурса.

Изменяемые предпосылки рекомендуется хранить в специально выделенном блоке или на отдельном листе.

```quiz
question: Почему изменяемую предпосылку лучше вынести из расчетной формулы?
A: Чтобы уменьшить размер файла
B: Чтобы у предпосылки был единый источник и изменение распространялось по модели
C: Чтобы скрыть формулу
D: Чтобы Excel быстрее запускался
correct: B
explanation: Изменяемая предпосылка должна иметь единый управляемый источник. Тогда изменение значения автоматически распространяется на все связанные расчеты.
```

## Контроль расчетов

Для ключевых расчетных блоков необходимо предусматривать контрольные проверки.

Можно использовать:

- контроль итоговых сумм;
- проверку пропусков;
- проверку знаков;
- сопоставление взаимосвязанных показателей;
- проверку балансов;
- контроль отклонений.

Контрольные показатели позволяют быстрее обнаруживать ошибки после изменения исходных данных или структуры модели.

### Пример контрольной проверки

```excel
=ЕСЛИ(ABS(Активы-Пассивы)<0,01;"OK";"Проверить")
```

Такая проверка позволяет автоматически контролировать выполнение заданного условия.

```quiz
question: Для чего в финансовой модели нужны контрольные проверки?

B: Для уменьшения количества листов
C: Для автоматического изменения исходных данных
D: Для скрытия промежуточных расчетов
correct: A
explanation: Контрольные проверки позволяют выявлять нарушения заданных условий и быстрее находить ошибки после изменения данных или расчетной логики.
```

## Итоги занятия

После занятия необходимо понимать следующие принципы:

- исходные данные, предпосылки, расчеты и представление результатов желательно разделять;
- изменяемые параметры не следует скрывать внутри расчетных формул;
- предпосылки должны иметь единый источник;
- расчетные блоки должны быть проверяемыми;
- контрольные показатели помогают выявлять ошибки модели.
